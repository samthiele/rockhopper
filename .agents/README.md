| Skill | When to load |
|-------|----------------|
| [`vft-development`](skills/vft-development/SKILL.md) | Tour content, `index.json`, Python `VFT` / clouds / Flask authoring; multi-style zarr stylesheets |
| [`rockhopper-frontend`](skills/rockhopper-frontend/SKILL.md) | React viewer, streaming, annotation UX, `src/` changes |
| [`vft-writing`](skills/vft-writing/SKILL.md) | Drafting or rewriting visitor-facing markdown — ask audience first |

Agents should read `AGENTS.md` first, then open only the skill(s) that match the task.
