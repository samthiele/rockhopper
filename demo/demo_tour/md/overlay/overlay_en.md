# Mesh and cloud

Multiple 3D objects, including several point clouds and/or meshes, can be loaded for a single site if needed. This could be used to e.g., integrate digital outcrop point clouds and interpolated 3D surfaces (triangulated meshes). Or, we can also make our penguin swim over a rock, to closely inspect it's gabbroic texture!

The list in the top-right of the 3D view can be used to toggle object visibility. **Photosphere** in the lower-right opens the panorama, and **3D View** comes back to the penguin and the rock.
